Ao final da campanha, a agência gera um link com os resultados. A marca abre esse link e vê a
performance consolidada, sem login.

## Como a agência gera

No detalhe da campanha, o botão **Relatório da marca** cria o link e o copia para a área de
transferência. Antes disso, vale usar **Atualizar métricas (auto)** para trazer os números mais
recentes das entregas publicadas.

## O que a marca vê

**Indicadores**

| Indicador | O que significa |
| --- | --- |
| Entregas | Quantidade de entregas medidas |
| Alcance | Contas únicas alcançadas |
| Impressões | Total de exibições |
| Engajamento | Interações somadas |
| Taxa de engajamento | Engajamento sobre alcance |
| Investimento | O valor investido na campanha |
| CPM | Custo por mil de alcance |
| Custo por engajamento | Investimento dividido pelo engajamento |
| EMV | Valor estimado de mídia espontânea |
| Receita atribuída | Receita associada à campanha, quando informada |
| ROI | Receita atribuída sobre investimento |

**Seções**

- alcance por plataforma;
- a lista das entregas da campanha.

O rodapé identifica o relatório como gerado pelo Mainstay.

## Quando o relatório aparece vazio

Se nenhuma entrega tiver métricas registradas, o relatório mostra **"Nenhuma entrega medida ainda"**.
Registre pelo menos alcance e impressões nas entregas publicadas antes de compartilhar.

## Problemas comuns

<ProblemaComum titulo='A marca vê "Relatório não encontrado ou link expirado"'>
Gere um novo link pelo botão **Relatório da marca** e reenvie.

</ProblemaComum>

<ProblemaComum titulo="ROI e receita atribuída aparecem zerados">
Esses indicadores dependem da receita atribuída ser informada. Sem esse dado, os demais indicadores
(alcance, engajamento, CPM, EMV) continuam válidos.

</ProblemaComum>
