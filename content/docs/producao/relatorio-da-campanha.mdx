O relatório da campanha é a prestação de contas para a marca: entregas publicadas, alcance,
engajamento e retorno. Ele é publicado como link, sem login.

<Permissoes>
Área **Campaign reports** — geração do link do relatório da campanha.

</Permissoes>

<PreRequisitos>
Ao menos uma entrega publicada com métricas registradas. Sem métricas, o relatório mostra *"Nenhuma
entrega medida ainda"*.

</PreRequisitos>

## Passo a passo

<Steps>

<Step>
### Atualize as métricas

No detalhe da campanha, use **Atualizar métricas (auto)** para coletar os números públicos das
entregas publicadas. O sistema informa quantas entregas foram atualizadas. Complete manualmente o que
faltar.

</Step>

<Step>
### Gere o link

Clique em **Relatório da marca**. O link é copiado para a área de transferência.

</Step>

<Step>
### Envie para a marca

</Step>

</Steps>

<Resultado>
A marca abre o relatório pelo link e vê os indicadores da campanha e a lista de entregas publicadas.

</Resultado>

## O que o relatório mostra

| Indicador | O que significa |
| --- | --- |
| Entregas | Quantidade de entregas medidas |
| Alcance | Contas únicas alcançadas |
| Impressões | Total de exibições |
| Engajamento | Interações somadas |
| Taxa de engajamento | Engajamento sobre alcance |
| Investimento | O que a marca investiu na campanha |
| CPM | Custo por mil de alcance |
| Custo por engajamento | Investimento dividido pelo engajamento |
| EMV | Valor estimado de mídia espontânea |
| Receita atribuída | Receita associada à campanha, quando informada |
| ROI | Receita atribuída sobre investimento |

Há ainda o alcance por plataforma e a lista das entregas da campanha.

<Callout title="Métricas alimentam tudo de uma vez">
  O mesmo dado que você registra na entrega abastece o relatório da marca e os relatórios internos de
  produção. Não existe um "preenchimento só para o relatório".

</Callout>

## Problemas comuns

<ProblemaComum titulo='A marca vê "Relatório não encontrado ou link expirado"'>
O link tem validade. Gere um novo pelo botão **Relatório da marca** e reenvie.

</ProblemaComum>

<ProblemaComum titulo="O relatório está vazio">
Não há entregas publicadas com métricas. Publique as entregas e registre pelo menos alcance e
impressões.

</ProblemaComum>
