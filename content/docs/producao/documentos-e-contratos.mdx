Os documentos da campanha ficam na aba **Documentos**. É por ali que passam contratos da marca,
aceites do influenciador, termos de autorização e anexos de briefing.

<Permissoes>
Área **Campaign documents** — cadastro, geração a partir de modelo, envio para assinatura e
marcação de assinado.

</Permissoes>

## Tipos de documento

| Tipo | Uso típico |
| --- | --- |
| Contrato da marca | O contrato principal da campanha |
| Aceite do influenciador | O aceite individual de cada influenciador |
| Termo de autorização | Autorizações de uso de imagem e conteúdo |
| Anexo de briefing | Materiais de apoio da campanha |
| Outro | Qualquer documento fora dos tipos acima |

## Passo a passo

<Steps>

<Step>
### Abra a aba Documentos

**Produção › Campanhas › Detalhes**, aba **Documentos**.

</Step>

<Step>
### Crie o documento

Use **Novo documento** para anexar um arquivo, ou **Gerar de template** para montar o documento a
partir de um modelo cadastrado em **Configuração › Modelos de contrato**. Os modelos aceitam
variáveis que são substituídas pelos dados da campanha e do influenciador.

</Step>

<Step>
### Envie para assinatura

Com o conteúdo pronto, use **Enviar para assinatura**. O documento sai pela integração de assinatura
digital configurada.

</Step>

<Step>
### Acompanhe

O status muda conforme o processo avança.

</Step>

</Steps>

## Ciclo de status

| Status | Significado |
| --- | --- |
| Rascunho | Em preparação |
| Pronto para envio | Conteúdo definido |
| Enviado | Enviado para assinatura |
| Visualizado | O signatário abriu |
| Assinado | Concluído |
| Rejeitado | Recusado pelo signatário |
| Cancelado | Encerrado pela agência |

<Resultado>
Documentos assinados aparecem com a data de assinatura e somem do alerta **sem contrato assinado**
em **Próximos passos** da campanha.

</Resultado>

## Marcar assinado manualmente

Quando a assinatura acontece fora do sistema, use **Marcar assinado**. A ação só é permitida para
documentos que já saíram para assinatura (pronto, enviado ou visualizado) — não dá para marcar como
assinado um rascunho.

## Do lado do influenciador

O influenciador vê os documentos que precisam da assinatura dele na aba **Contratos** do
[portal](/docs/producao/portal-do-influenciador). Cada um enxerga apenas a própria URL de assinatura.

## Problemas comuns

<ProblemaComum titulo='"O documento precisa ter conteúdo antes de ser enviado para assinatura"'>
O documento está sem corpo gerado e sem URL de arquivo. Gere o conteúdo a partir de um modelo ou
anexe o arquivo antes de enviar.

</ProblemaComum>

<ProblemaComum titulo='"Só é possível marcar como assinado um documento que já saiu para assinatura"'>
Envie o documento primeiro (ou marque-o como pronto para envio) e então registre a assinatura.

</ProblemaComum>
