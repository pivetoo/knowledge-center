Publicar é registrar que o conteúdo foi ao ar. É o passo que fecha a produção e abre o financeiro:
a publicação gera o custo do influenciador.

<Permissoes>
Área **Campaign deliverables** — "Permite atualizar os dados de uma entrega de campanha".

</Permissoes>

<PreRequisitos>
A entrega precisa ter **uma aprovação registrada** (da marca ou interna) e você precisa ter a **URL
do post publicado**.

</PreRequisitos>

## Passo a passo

<Steps>

<Step>
### Abra a entrega

**Produção › Campanhas › Detalhes**, aba **Entregas**.

</Step>

<Step>
### Informe a URL publicada

Cole o endereço do post no campo **URL publicada**. Ele é obrigatório para marcar a entrega como
publicada.

</Step>

<Step>
### Marque como publicada

Altere o status da entrega para **Publicada** e salve.

</Step>

</Steps>

<Resultado>
A entrega fica como **Publicada** e o repasse do influenciador é gerado no Financeiro com o valor
real da entrega. A partir daí ele aparece em **Financeiro › Repasses para influenciadores**.

</Resultado>

## O gate de aprovação

Por padrão, a entrega só pode ser publicada depois de aprovada. O sistema aceita qualquer uma das
duas aprovações:

- **da marca**, registrada pelo link público;
- **interna**, registrada pela agência na revisão de conteúdo.

Esse gate pode ser desligado por campanha, desmarcando **Exigir aprovação da marca para publicar
entregáveis** no cadastro da campanha. Mantê-lo ligado é o padrão recomendado.

## Depois de publicar

- [Registre as métricas](/docs/producao/metricas) do post (alcance, impressões, engajamento).
- O relatório da campanha passa a considerar esta entrega.
- Se a campanha usa **pay-when-paid**, o repasse só é agendado quando todas as entregas daquele
  influenciador estiverem aprovadas.

## Problemas comuns

<ProblemaComum titulo='"A entrega só pode ser publicada após aprovação da marca"'>
Não há aprovação registrada para esta entrega. Aprove internamente na revisão de conteúdo ou envie o
link de aprovação para a marca. Veja
[entregável bloqueado](/docs/solucao-de-problemas/entregavel-bloqueado).

</ProblemaComum>

<ProblemaComum titulo='"A URL de publicação é obrigatória para entregas publicadas"'>
Preencha o campo **URL publicada** antes de mudar o status.

</ProblemaComum>
