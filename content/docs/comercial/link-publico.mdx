O link público é o endereço que a marca abre para ver a proposta, baixar o PDF e registrar a decisão
— tudo sem login.

<Permissoes>
Área **Proposals** — "Permite gerar um novo link público para uma proposta" e "Permite revogar um
link público de proposta".

</Permissoes>

<PreRequisitos>
A proposta precisa ter sido enviada ao menos uma vez. Enquanto ela estiver em rascunho, a aba de
compartilhamento orienta: *"Envie a proposta antes de compartilhar"*.

</PreRequisitos>

## Gerar um link

<Steps>

<Step>
Abra a proposta e vá até a aba de compartilhamento.

</Step>

<Step>
Em **Gerar novo link**, informe a **Validade (opcional)**.

</Step>

<Step>
Clique em **Gerar link público** e depois em **Copiar**.

</Step>

</Steps>

<Resultado>
O link entra na lista de **Links públicos** com status **Ativo**, data de criação, expiração e última
visita.

</Resultado>

<Callout title="O envio já gera link">
  Você não precisa gerar o link manualmente para enviar a proposta: o envio por e-mail ou WhatsApp já
  garante um link. A geração manual serve para compartilhar por outro caminho ou criar um link com
  validade diferente.

</Callout>

## O que a marca vê

A versão **congelada no momento do envio** — itens, valores e desconto como estavam naquela hora,
imunes a edições posteriores na proposta. O link sempre aponta para a versão mais recente enviada.

## Engajamento

A mesma aba mostra:

- **Aberturas** — quantas vezes o link foi aberto;
- **Primeiro acesso** e **Último acesso**;
- o dispositivo usado (computador, celular, tablet);
- uma linha do tempo das visualizações;
- **Versões enviadas**, com autor, data e até quando cada versão era válida;
- **Envios**, com o resultado de cada disparo.

## Revogar um link

Use **Revogar** na linha do link. O sistema confirma: *"Revogar este link? Quem já abriu não consegue
acessar mais."* Depois disso, tanto a página quanto o PDF param de responder.

Links **rejeitados**, **cancelados** ou **vencidos** também deixam de funcionar automaticamente.

| Status do link | Significa |
| --- | --- |
| Ativo | Funcionando |
| Expirado | Passou da validade |
| Revogado | Desativado manualmente |

## Problemas comuns

<ProblemaComum titulo="O cliente diz que o link não abre">
Confira o status na lista de links. Expirado, revogado ou proposta cancelada resultam em página
indisponível. Gere um link novo e reenvie.

</ProblemaComum>

<ProblemaComum titulo="O cliente está vendo valores antigos">
Ele está com um link de uma versão anterior — ou a proposta foi alterada e ainda não reenviada. Um
novo envio gera uma nova versão e o link passa a mostrá-la.

</ProblemaComum>
